# 📱 手机页面模拟器 - 完整项目文档索引

> **Meituan Hackathon 项目** | 基于 Vue 3 + TypeScript + Vite 的专业手机设备模拟工具

---

## 🎯 项目概览

本项目是为美团周末活动规划应用开发的**专业级手机页面模拟器**，提供：

✨ **4 种 iPhone 设备** (iPhone 14/15/16/16 Pro)  
✨ **6 项互动控制** (亮度、缩放、旋转等)  
✨ **完全响应式** (桌面/平板/手机适配)  
✨ **实时预览** (Hot Reload 支持)  
✨ **完善文档** (10,000+ 字技术文档)
